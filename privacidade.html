Política de Privacidade

Última atualização: 07/11/2026.

O aplicativo "YouTube Automation" é uma ferramenta de uso pessoal. Ele acessa, com autorização do próprio dono, apenas os canais de YouTube do seu autor, para enviar e agendar vídeos (escopos youtube.upload e youtube.readonly).

Dados acessados

Nome e ID do canal e os vídeos enviados pelo próprio autor. Nenhum dado de terceiros é coletado.

Armazenamento e compartilhamento

Os tokens de acesso ficam apenas no computador do autor. Nenhum dado é vendido, compartilhado ou transferido a terceiros, nem usado para publicidade ou para treinar modelos.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
